# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/lennartschweizer/break-keeper/security/advisories/new) instead of opening a public issue.

Include a brief description of the issue and steps to reproduce it.
